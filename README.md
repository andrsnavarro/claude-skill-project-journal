# claude-skill-project-journal

A skill that keeps a living project journal up to date without being asked. It updates the journal right after important decisions, keeps a CURRENT STATE block on top, logs killed ideas with their reason, and includes formats for a main journal, product diary, status per iteration, open questions, changelog and content journal. Claude replies in your language.

## Install

Copy this folder into your skills directory, for example `~/.claude/skills/project-journal`.
